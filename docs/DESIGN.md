## 이 앱 고유 결정
- **핀 5색**은 DW 잉크 팔레트에서 뽑았다(맛집 #DF4B46 · 관광지 #3D79C0 · 카페 #93550F · 숙소 #006F6C · 기타 #88837C) — 형광 원색 금지, 눌러 쓴 잉크 무게.
- 지도 위 플로팅: AI 맛집(파란 알약, 아래 가운데) · 내 위치(흰 원, 오른쪽 아래).
- 일정 타임라인: 순번 점(파랑 틴트) + 시각 입력(고정 폭 `.dw-input--time`) + 순서 이동.
- `.dw-input`은 폭 100%가 기본이라 폭·여백을 바꿀 땐 전용 변형(`--icon`, `--time`)을 쓴다
  (Tailwind 도구 클래스는 레이어라서 비레이어 규칙에 진다 — 2026-08-08 실측로 확인).
- **검색 자동완성**(2026-08-08): 입력칸 바로 아래 흰 카드(R16) 후보 목록 — 내 핀(이모지)이
  먼저, 장소(MapPin 아이콘)가 다음. 이름 굵게 + 주소 한 줄(muted). 검색 결과 자리는
  잉크 파랑 점(`.search-dot`, 흰 테두리 3px) + 물결 애니메이션으로 표시하고, 말풍선에서
  바로 "핀으로 저장"(이름 미리 채움). 장소 사전은 Photon(`lang=default` = 현지 이름,
  지도 라벨과 동일 원칙), 예비는 Nominatim(엔터 시에만 — 자동완성 금지 규칙 준수).

- **줄 목록 규칙**(2026-08-08, 리스트 화면 개선): 같은 종류의 줄이 여럿이면 **카드는 하나만
  띄우고 줄은 머리카락 굵기 선으로 나눈다**(`.dw-list`/`.dw-row`). 낱장 카드를 45장 늘어놓으니
  한 화면에 8줄만 들어가고 흰 띠 밭처럼 보였다 → 카드 한 장 안에 쌓아 11줄로 늘렸다.
  ① 이름은 **두 줄까지 늘어난다**(가운데서 자르면 어느 가게인지 알 수 없다),
  ② 종류는 진한 원 대신 **종류 색을 13%로 옅게 깐 네모 + 그 색 아이콘**(`.dw-swatch`) —
  같은 원을 45번 반복하면 화면이 시끄럽다, ③ 줄에 두는 단추는 **지도 하나뿐**,
  지우기는 펼친 안쪽으로 내렸다(스쳐서 지워지는 사고 방지 + 이름 자리 확보),
  ④ 45줄 모두 붙는 `AI` 표는 회색(`.dw-tag--muted`), 드물게 붙는 `친구` 표만 파랑.
- **빈 화면 규칙**(2026-08-08): 글로 길게 설명하지 않고 **그림 하나 + 한 줄**만 둔다
  (`.dw-empty`). 비서 화면에 예시 부탁 알약을 깔아 봤으나 운영자가 제거를 지시해 뺐다
  (2026-08-08) — 비서 화면은 입력칸 하나로 충분하고, 안내 알약은 군더더기라는 판단.
  `.dw-empty`는 리스트 화면(꽂아 둔 곳이 없을 때)에만 쓴다.
