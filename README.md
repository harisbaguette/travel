# 🗺️ 여행 핀 지도

지도에 가고 싶은 곳을 콕콕 찍어 두고, 날짜별로 나눠 계획을 세우는 여행 앱.
로그인 없이 링크만 나눠 주면 친구와 같이 편집할 수 있다.

- 지도: Leaflet + OpenFreeMap 벡터 지도 (무료, 키 불필요) — 지명이 한국어로 나온다
- 맛집 찾기: Overpass API (OpenStreetMap 데이터, 무료)
- 함께 편집: Neon (인터넷 Postgres) — 접속 주소가 없으면 자동으로 혼자 쓰기 모드

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
```

## 기능

| 기능 | 설명 |
|------|------|
| 한국어 지도 | 지명이 한국어로(없으면 현지어). 도시·장소 검색 이동 |
| 핀 | 맛집🍜 관광지📸 카페☕ 숙소🛏 기타📍 — 추가·삭제·드래그·메모 |
| 맛집 긁어오기 | 지금 보이는 지도 범위의 음식점·카페를 최대 15개 자동 추가 (키 불필요) |
| 비서 | 말로 부탁하면 네이버 블로그 후기를 찾아 핀 후보를 만들어 온다. 후보마다 출처 링크가 붙는다 |
| 여행 방 | 방마다 핀·일정 따로 저장. `?room=xxx` 링크로 참여, 방에 맞는 지도 위치로 이동 |
| 일정 타임라인 | Day 카드에 핀을 배정하고 방문 시각·순서 기록 |
| 여행 기록 | 비행(가는/오는 편)과 숙소(체크인/아웃) 기록 — 방 전체가 같이 본다 |
| 모바일 | 하단 탭(지도/핀/일정/기록) + 내 위치 버튼 |
| 함께 편집 | 내 핀은 색 테두리, 친구 핀은 회색 점선 테두리 |

## 함께 편집 켜기 (선택)

접속 주소가 없어도 앱은 그대로 동작한다 (내 브라우저에만 저장).
여러 사람이 같이 편집하려면 [Neon](https://neon.com)에서 무료 Postgres를 만들고
`.env.local`에 접속 주소를 넣는다:

```bash
cp .env.example .env.local
# DATABASE_URL=postgresql://...neon.tech/neondb?sslmode=require
```

테이블은 `src/lib/schema.sql` 한 파일에 다 들어 있다. Neon 콘솔의 SQL 편집기에
붙여넣거나 psql로 실행한다 (여러 번 실행해도 안전하다).

### 왜 폴링인가

Neon은 데이터베이스만 제공하고, Supabase처럼 "바뀌면 즉시 알려주는" 기능은 없다.
그래서 이 앱은 3초마다 "그 시각 이후 바뀐 것 있어?"라고 물어보는 방식으로 맞춘다.
바뀐 것만 골라 오므로 오가는 양이 적고, 다른 탭을 보고 있으면 아예 묻지 않는다.
두세 명이 여행 계획을 짜는 용도에는 이 정도로 충분하다.

## 비서 켜기 (선택)

비서(채팅으로 시키는 화면)는 열쇠 두 종류가 있어야 움직인다. 없으면 비서 화면에만
안내가 뜨고 나머지 기능은 그대로 쓸 수 있다.

- `DEEPSEEK_API_KEY` — [platform.deepseek.com](https://platform.deepseek.com)에서 발급
- `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` —
  [developers.naver.com](https://developers.naver.com)에서 애플리케이션 등록 →
  사용 API에 "검색" 선택

비서는 네이버 블로그 후기만 근거로 삼는다. 검색 결과에 없는 링크를 붙인 후보는
서버가 버리므로, 화면에 나오는 출처 링크는 실제로 열리는 글이다.

## 배포

Vercel에 그대로 올라간다. 함께 편집을 쓰려면 `DATABASE_URL`,
비서까지 쓰려면 `DEEPSEEK_API_KEY`·`NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`을
Vercel 프로젝트 환경 변수에 등록한다.
